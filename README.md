# AutoDoc

Website otomatisasi dokumen-dokumen penunjang pekerjaan di Satuan Pelayanan Pemenuhan Gizi Gratis Darmaraja 01.

## Pratinjau halaman awal

Saat ini repository berisi prototipe halaman sambutan, login token/PIN, dan beranda awal yang responsif untuk desktop, tablet, dan smartphone.

### Menjalankan secara lokal

1. Unduh repository atau file `index.html`.
2. Buka `index.html` menggunakan browser modern (Chrome, Edge, Firefox, atau Safari).
3. Masukkan teks apa pun pada kolom token/PIN untuk melihat alur pratinjau menuju beranda.

> **Catatan keamanan:** alur masuk pada prototipe ini belum melakukan autentikasi sungguhan. Jangan gunakan token atau PIN rahasia pada versi pratinjau. Validasi akses perlu dihubungkan ke backend Supabase sebelum dipakai operasional.

## Teknologi

- HTML, CSS, dan JavaScript murni (tanpa dependensi build).
- Layout responsif dengan breakpoint untuk layar kecil, tablet, dan desktop.
- Siap dikembangkan dengan integrasi Supabase untuk autentikasi token/PIN dan penyimpanan data.
