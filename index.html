Setup Awal AutoDoc

PIN MASUK sudah disimpan sebagai secret di Supabase. Masukkan PIN tersebut untuk menyelesaikan pengaturan awal dan mengunci nomor awal dokumen.

PIN dicocokkan di server dengan secret Supabase dan disimpan ke database hanya sebagai hash bcrypt. Nilai PIN tidak dikirim kembali ke browser.

PIN tidak disimpan dalam bentuk teks biasa. Setelah Setup Awal selesai, nomor awal tidak dapat diubah tanpa verifikasi PIN.
